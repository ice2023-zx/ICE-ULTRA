ICE-X WhatsApp Bot v3
1) Upload these files to the ROOT of your server (index.js must not be inside a folder).
2) Startup tab: JS file = index.js
3) Start the server and wait for the "PAIRING CODE" in the console.
4) WhatsApp > Linked devices > Link with phone number > enter the code.
Edit OWNER_NUMBER / COUNTRY_CODE at the top of index.js.
